iPadホーム画面用 英単語暗記アプリ

使い方:
1. このフォルダ一式をHTTPSで公開します。
2. iPadのSafariで index.html のURLを開きます。
3. 共有ボタン -> 「ホーム画面に追加」 -> 追加。
4. ホーム画面の「えいたんご」から起動します。

重要:
- iPad Safariでは音声の自動再生が制限される場合があります。最初の起動時に一度画面をタップすると、その後の自動読み上げが安定しやすくなります。
- 単語リストは同じiPadのSafariのブラウザ保存領域に保存されます。SafariのWebサイトデータを削除すると失われる可能性があります。
